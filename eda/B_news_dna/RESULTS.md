# 뉴스 DNA 유형화 — 2025 언론수용자 조사 클러스터링 (B담당)

## 핵심 발견
- **한국인 뉴스 소비는 6개 유형으로 갈린다** (K-means, k=6, 매체별 뉴스 이용 일수 12개 + 참여행태, n=6,000, 가중치 적용 비율):
  **TV 순정파 28.3% / 본방+포털 투트랙 24.3% / 뉴스 미니멀족 17.7% / 포털 텍스트파 11.8% / 영상 뉴스 대식가 10.9% / 단톡방 전파자 7.0%**
- **연령만으로는 유형이 결정되지 않는다**: 연령 단독 예측 정확도 39.6%(베이스라인 30.7%와 5%p 차이). 20대 안에서도 미니멀족 32%, 포털 텍스트파 30%, 단톡방 전파자 12%, 투트랙 12%로 갈림.
- **진단 테스트 실현 가능**: 설문 5문항(TV/포털/동영상/숏폼/메신저 뉴스 이용 일수)만으로 유형 예측 **CV 정확도 92.4%**, 8문항이면 **93.5%** (의사결정나무, 5-fold 층화 CV).
- 클러스터링은 강건함: 시드 5개 ARI 0.91~1.00, 부트스트랩(80% 서브샘플) ARI 평균 0.92, Ward 계층 클러스터링과 ARI 0.51(대형 4개 유형 구조 일치).
- 국민의 **17.7%(뉴스 미니멀족)는 모든 매체에서 주 1일 안팎만 뉴스 접촉** — 평균 연령 44세로 고령층이 아니라 2040이 주축(20~40대 63%).
- **단톡방 전파자(7.0%)가 뉴스 생태계의 확성기**: 공유 경험 88%, 댓글 53%로 압도적(전체 평균 공유 13%). 유료 이용 의향도 7.1%로 전 유형 중 최고(전체 2.1%).

## 방법
1. **피처**(01_features.py): 매체별 '뉴스' 이용 주간 일수 12개(평일 0~5 + 주말 0~2 = 0~7일)로 통일.
   - 스킵 로직 규칙: 게이트 문항(예: 문61 숏폼 뉴스 이용 여부)이 '이용'이 아니면 0일, 일수 문항 스킵 결측도 0일.
   - 포털은 모바일/PC 기기별 일수의 **max**(중복 계상 방지). 참여 = 포털/메신저/SNS/동영상 4개 플랫폼에서 공유·추천·댓글 각 1회 이상(0~3점).
2. **스케일링**: z-score가 아닌 **range scaling(일수/7, 참여/3)**. z-score는 이용률 1~2%인 희소 매체(팟캐스트·AI)와 유료의향(2%)의 z가 7~16까지 폭주해 인공 미세 클러스터를 만들었음(실루엣 0.09, Ward ARI 0.16 → range scaling 시 0.29/0.51).
3. **태도 변수(관심·신뢰·유료의향)는 클러스터링에서 제외**하고 프로파일링으로 검증 — 포함 시 실루엣 0.20 vs 미포함 0.29로 매체 레퍼토리 구조가 흐려짐.
4. **k 선택**(kselect.csv): k=3~10 비교. 실루엣은 k≥6에서 0.29~0.31로 평탄, k=7 이상은 최소 클러스터가 6% 미만으로 쪼개지고 해석 중복(영상 대식가 분할) 발생 → **k=6** (실루엣 0.294, 시드 ARI 0.91~1.00, 부트스트랩 ARI 0.92, 최소 클러스터 7.0%).

## 진단 테스트

### 실현성 검증 (04_quiz_tree.py / quiz_tree.txt)
- 베이스라인(최빈 유형 찍기) 30.7%.
- 5문항(TV/포털/동영상/숏폼/메신저 이용 일수) → **92.4%**, +공유 경험 6문항 → 92.7%, +SNS·댓글 8문항 → **93.5%** (의사결정나무, 원 일수 0~7 입력, 5-fold 층화 CV).
- 분기 4번 이하의 초간단 규칙(6문항, depth=4)도 90.6% → "1분 자가진단 테스트"로 구현 가능. 첫 분기: 포털 주 2.5일, TV 주 3.5일.

### 최종 웹 모델 (05_quiz_simulation.py / quiz_model.json)
- 실제 퀴즈는 일수를 5지선다 구간(0 / 1 / 2~3 / 4~5 / 6~7일 → 0/1/2.5/4.5/6.5)으로만 받으므로, 응답자 6,000명을 구간값으로 뭉갠 뒤에도 분류가 유지되는지 시뮬레이션.
- 입력 축 7개: TV/포털/동영상/숏폼/메신저/SNS 일수 + 참여도(공유·좋아요·댓글 경험 개수 0~3).
- **채택: nearest centroid**(클러스터별 원 일수 평균과의 최근접, 일수/7·참여/3 스케일링) — 전체 설문 기반 유형과의 **일치도 92.4%**. 구간값으로 재학습한 트리(89.5%)보다 정확하고, 2순위 중심으로 '서브 DNA'까지 제공 가능해 채택.
- 클래스별 재현율: 미니멀족 98.8% / TV 순정파 98.0% / 단톡방 전파자 97.1% / 포털 텍스트파 94.8% / 영상 대식가 90.3% / **투트랙 79.4%(최저)** — 투트랙은 TV·포털 축이 순정파/텍스트파와 인접해 구간화 시 경계 손실이 가장 큼.
- quiz_model.json은 웹(`web/src/`)과 동일 파일로 출력되며, 유형 이름·가중 비율·매체별 가중 이용일수도 포함해 웹 화면 수치의 단일 소스로 사용.

## 검증 (공식 보고서 대조)
- 매체별 뉴스 이용률(가중) 10종 모두 보고서(p.19~20, 그림 1-1)와 **소수점 첫째 자리까지 완전 일치**: TV 81.4%, 포털 66.5%, 동영상 30.0%, 숏폼 22.9%, 메신저 13.4%, 종이신문 8.4%, SNS 8.1%, 생성형 AI 2.1%, 잡지 1.9%, 팟캐스트 1.1%.
- 보고서의 '숏폼 뉴스 이용자 n=1,376'은 **가중 인원**(6,000×22.9%)임을 확인 — 비가중 응답자 수는 1,231명. 인용 시 주의.

## 데이터 품질 이슈
- 참여행태 문항(문35 등)의 9997/9999 코드는 '없음'으로 처리(발견된 실제 응답은 1/2뿐).
- 유료 이용 의향(문97_1)은 전체 2.1%로 희소 — 클러스터링 피처로 쓰면 인공 클러스터 발생, 프로파일 변수로만 사용.
- OTT·생성형AI·팟캐스트·잡지 뉴스는 이용률 1~4%대라 유형 형성에 기여 없음(피처에는 포함, 분리 기여는 미미).
- 가중치 WT 존재, 모든 비율·평균에 적용. 클러스터 학습 자체는 비가중(관측치 단위), 크기·프로파일은 가중.
